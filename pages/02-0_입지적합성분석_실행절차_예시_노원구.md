# 실행 절차 결정사항 예시 (노원구 사례)

실제 분석에서는 각 팀이 직접 판단하여 이 칸을 채워야 하며, 아래 내용은 어디까지나 참고용 예시 답안이다.

---

## 1. GIS-MCDA 실행 절차 예시

| 순서 | 실행 내용 | 결정사항 (예시) |
|---|---|---|
| 1 | 문제 정의 | 목적: 노원구 신규 대피소 우선순위 지역 도출<br>대상 지역: 서울 노원구<br>대안 단위: 격자(사각형)<br>격자 간격: 500m (도시계획 분야 도보 서비스권 기준 약 400~800m 참고, 민방위 대피시설 전용 공식 기준은 확인되지 않음 → 3차시에서 250m·750m로 재검토) |
| 2 | 기준도 작성 | 기준 ①: 인구밀집도 (출처: SGIS 행정동 경계·인구)<br>기준 ②: 기존 대피소와의 거리 (출처: 공공데이터포털 전국민방위대피시설표준데이터)<br>기준 ③: 도로 접근성 (출처: 국토교통부 도로중심선) |
| 3 | 좌표계 확인 | 원본 레이어 좌표계: 각각 확인 필요<br>분석용 투영좌표계: EPSG:5179로 통일 |
| 4 | 기준별 점수화 | 인구밀도 = 인구수 / 면적 (위치 기반 조인)<br>대피소거리 = 최근접 허브까지 거리 (멀수록 유리)<br>도로거리 = 최근접 도로까지 거리 (가까울수록 유리) |
| 5 | 정규화(제1부 4절) | 방법: 최소-최대 정규화<br>방향 반전: 도로거리만 (1−정규화값)으로 반전 |
| 6 | 가중치 부여(제1부 5절) | 결정 방법: 팀 토론<br>인구밀집도: 0.4<br>대피소거리: 0.3<br>도로접근성: 0.3 |
| 7 | 제약조건 처리(제1부 6.1절) | 사전 제약조건 레이어: 없음<br>사후 처리: 3차시에서 위성영상으로 하천·공원·학교·급경사지 등을 확인해 필요시 제외 |
| 8 | 중첩 분석 | 결합 방식: SAW(가중선형결합)<br>공식: 적합도점수 = (인구밀도_정규화×0.4) + (대피소거리_정규화×0.3) + (도로거리_정규화_역산×0.3)<br>도구: QGIS 필드 계산기 |
| 9 | 결과 검증 | 시각화: 단계구분(Jenks 자연구간)<br>산출물: 인쇄 레이아웃(범례·축척·방위표·출처 표기 포함) |

## 2. 민감도 분석 실행 절차 예시

| 순서 | 실행 내용 | 결정사항 (예시) |
|---|---|---|
| 1 | 검토 대상 변수 선정 | 변수 ①: 격자 간격<br>변수 ②: 가중치 |
| 2 | 대안 시나리오 구성 | 격자 간격: 기준값 500m 대비 250m·750m로 변경<br>가중치: 기준값(0.4/0.3/0.3) 대비 균등(0.33/0.33/0.33) 및 팀 토론에서 제기된 대안 가중치 |
| 3 | 재산출 | 각 시나리오에 대해 위 1절의 정규화~중첩 분석 과정을 반복 수행 |
| 4 | 비교 지표 설정 | 지표: 시나리오별 상위 10위 목록의 일치 개수 |
| 5 | 결과 해석 | 격자 간격·가중치를 바꿔도 공통적으로 상위권을 유지하는 지역 식별 |
| 6 | 기록 | 위성영상 확인 결과: 상위 5개 후보지 중 건립 불가 지역(하천·공원·학교·급경사지 등) 포함 여부<br>기록 위치: 발표 자료 "한계" 항목 |
