# 프로젝트2 실습 절차 — 결정사항 예시 (노원구 사례)

이 문서는 이론문서(`03_프로젝트2_뉴스지명추출_.md`) 제2부의 두 표(텍스트 기반 위치 정보 추출 실행 절차 / 공간조인 및 주제도 제작 실행 절차)에서 비워 둔 "결정사항" 칸을, 노원구 프로젝트를 실제로 진행하며 내린 결정으로 채운 예시이다. 내용은 프로젝트2 학습정리 문서(1~3장)에 근거한다.

---

## 1. 텍스트 기반 위치 정보 추출 실행 절차 — 결정사항 예시

| 순서 | 실행 내용 | 확인·결정할 사항 | 결정사항 (예시) |
|---|---|---|---|
| 1 | 문제 정의 | 분석 목적, 대상 텍스트 출처, 검색 키워드 | **목적**: 노원구 뉴스 보도가 구 내 특정 동에 편중되어 있는지 동 단위로 확인. **출처**: 뉴스(구글 뉴스 RSS) — 민원 게시판은 원문 비공개, SNS는 지명 언급 비율이 낮아 제외. **키워드**: "노원구" |
| 2 | 데이터 수집 경로 확정 | 사용 가능한 API/RSS 여부, 접근 제약 | 최초 네이버 뉴스 검색 API를 검토했으나 개인 신규 발급이 정책적으로 중단된 상태임을 확인. 이에 구글 뉴스 RSS(가입 불필요) + 카카오 지오코딩 REST API(즉시 셀프 발급)로 경로를 전환 |
| 3 | 지명 인식 방법 선택 | 목록 매칭/정규표현식/개체명 인식 중 선택, 대상 지명 목록의 범위 | 목록 매칭 방식 채택(정규표현식보다 정확). 대상 목록은 노원구 소속 행정동 전체(정식 동명과 축약 표기를 모두 포함) |
| 4 | 수집 표본 규모 결정 | 검색 결과 최대 건수, 검색 단위 | 초기값 `MAX_ITEMS=50`(서버 제약이 아니라 API 호출량을 고려한 임의값). 이후 100으로 늘려 표본 변화를 비교하고, "노원구" 대신 동 이름별로 개별 검색해 표본을 늘리는 방법과 `when:` 파라미터로 수집 기간을 직접 지정하는 방법을 함께 검토 |
| 5 | 지오코딩 수행 | 사용할 지오코딩 서비스, 캐싱 등 API 호출 최적화 방법 | 카카오 지오코딩 API 사용. 동일한 동은 캐시에 저장해 재사용, API 호출 횟수 절약. 지오코딩 대상은 기사 본문의 구체적 위치가 아니라 "동 이름" 자체이므로, 같은 동을 언급한 기사는 모두 동일한 좌표로 지오코딩됨(한계로 명시 필요) |
| 6 | 결과 저장 형식 결정 | GIS 소프트웨어에서 바로 불러올 수 있는 저장 형식, 좌표계 명시 여부 | CSV(위도·경도 컬럼 포함, QGIS "구분자로 분리된 텍스트 레이어 추가"로 로드)와 Shapefile(.shp/.dbf/.shx/.prj, 좌표계 EPSG:4326 명시, QGIS "벡터 레이어 추가"로 로드) 두 형식으로 저장 |

## 2. 공간조인 및 주제도 제작 실행 절차 — 결정사항 예시

| 순서 | 실행 내용 | 확인·결정할 사항 | 결정사항 (예시) |
|---|---|---|---|
| 1 | 주제도 변수 선택 | 시각화할 값, 분류기법 후보 | 값: 노원구(행정경계) 레이어의 `pop`(인구) 필드. 분류기법 후보: 등간격(Equal Interval), 분위수(Quantile), 자연분류(Natural Breaks, Jenks) |
| 2 | 분류기법 비교 | 동일 변수에 여러 분류기법을 적용했을 때 지도 해석이 어떻게 달라지는지 확인 | 세 분류기법을 각각 5단계로 적용해 지도 색 분포 변화를 스크린샷으로 남겨 비교 |
| 3 | 조인 방식 선택 | 속성조인 vs 공간조인, 사용할 공간 조건자 | 뉴스 포인트와 행정동 폴리곤 사이에 공유하는 공통 컬럼이 없으므로 공간조인 사용. 조건자는 Intersects |
| 4 | 조인 대상 레이어 확정 | 포인트 레이어와 결합할 폴리곤 레이어 | Input layer: 1장에서 만든 뉴스 포인트 레이어(CSV 또는 Shapefile). Join layer: `노원구(행정경계)` 폴리곤 레이어 |
| 5 | 조인 결과 검증 | 각 포인트에 올바른 속성이 결합되었는지 확인 | 결과 속성테이블에서 각 뉴스 포인트에 붙은 행정동 이름 필드를 확인. 포인트 수는 실제 지오코딩 성공 건수에 따라 팀마다 다를 수 있어, 정해진 개수보다 "올바른 동에 매칭되었는가"에 집중 |
| 6 | 스토리텔링 구성 | 문제제기-분석-시사점 구조에 따른 지도 배치, 표본 대표성의 한계 명시 여부 | 문제제기: "노원구 뉴스는 어디를 얼마나 다루고 있을까?" / 분석: 뉴스 지명 분포 + 인구밀도 분류기법 비교 / 시사점: "인구가 많은 동일수록 뉴스에도 더 많이 언급되는가?"라는 질문 제기. 표본 수가 적을 수 있어 정량적 결론 대신 경향성 제시와 한계 명시로 다룸 |
