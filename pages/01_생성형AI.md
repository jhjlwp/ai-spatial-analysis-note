### AI(Artificial Intelligence, 인공지능)
#### 생성형AI(Generative AI)
텍스트, 이미지, 코드, 음악, 영상 등 새로운 콘텐츠를 생성하는 인공지능 기술을 통칭
  * 텍스트 생성(LLM 기반)
  * 이미지 생성
  * 영상 생성
  * 음악·음성 생성
  * 코드 생성
##### LLM(Large Language Model, 거대언어모델)
방대한 양의 텍스트 데이터를 학습하여 다음에 올 단어(토큰)을 예측하는 방식으로 작동하는 대규모 신경망 모델
  * Claude Haiku 4.5, Claude Sonnet 5, Claude Opus 5, Claude Fable 5.1, Gemini 3.1 Pro, Gemini 3.7 Flash
  * LLM 성능 비교 사이트
    [Livebench](https://livebench.ai/#/)
