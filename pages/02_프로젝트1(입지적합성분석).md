# 입지 적합성 분석의 개념과 이론

# 제1부. 기본 이론

## 1. 입지 적합성 분석의 정의

입지 적합성 분석(Site Suitability Analysis)은 특정 목적(시설 건립, 토지이용 배치, 자원 개발 등)에 가장 적합한 위치를 찾기 위해, 여러 지리적 대안(지점, 구역, 격자 등)을 다수의 평가 기준에 따라 비교·평가하는 공간 분석 방법이다.

평가 대상이 되는 여러 위치는 각각 서로 다른 특성(인구, 접근성, 지형, 토지이용 등)을 가지며, 이 특성들은 목적에 따라 유리하게 작용하기도 하고, 불리하게 작용하기도 한다. 입지 적합성 분석은 이러한 다수의 특성을 하나의 종합적인 평가 기준으로 통합하여, 대안들 간의 상대적 우선순위를 산출하는 것을 목표로 한다.

---

## 2. 다기준 의사결정분석(MCDA)

### 2.1 정의

다기준 의사결정분석(Multi-Criteria Decision Analysis, MCDA)은 서로 다른 여러 평가 기준을 동시에 고려하여 여러 대안 중 최선의 대안을 선택하거나 우선순위를 결정하는 의사결정 방법론이다. 단일 기준으로는 명확히 판단하기 어려운 문제, 즉 기준들이 서로 다른 방향을 가리키는 문제(예: 비용은 낮추면서 성능은 높여야 하는 경우)를 다루기 위해 발전하였다.

### 2.2 방법의 분류

MCDA 기법은 대안 간 값의 차이를 서로 상쇄(보상)할 수 있는지에 따라 크게 두 가지로 구분된다.

- **보상적 방법(Compensatory method)**: 한 기준에서 낮은 점수를 다른 기준의 높은 점수로 상쇄할 수 있다고 보는 방법이다. 단순가중합법(SAW), TOPSIS 등이 이에 해당한다.
- **아웃랭킹(비보상적) 방법(Outranking / Non-compensatory method)**: 대안들을 둘씩 비교하여 어느 쪽이 더 우수한지 판정하는 방법이다. ELECTRE, PROMETHEE 등이 이에 해당한다. 이 방법은 한 기준에서 지나치게 낮은 값을 다른 기준의 높은 값으로 상쇄하지 않으려 하므로 비보상적 방법으로 분류된다. 다만 기법에 따라 상쇄를 완전히 배제하지는 않는 경우도 있어, "완전한 비보상"보다는 "상쇄를 최소화하는 방법"으로 이해하는 편이 정확하다.

입지 적합성 분석에서는 대체로 계산과 해석이 상대적으로 단순한 보상적 방법이 널리 사용된다.

### 2.3 핵심 구성요소

| 구성요소 | 의미 |
|---|---|
| 대안(Alternative) | 평가 및 비교의 대상이 되는 위치 또는 공간 단위 |
| 기준(Criteria) | 대안을 평가하는 개별 항목 |
| 가중치(Weight) | 기준별 상대적 중요도를 나타내는 값 |
| 정규화(Normalization) | 단위가 서로 다른 기준 값을 동일한 척도로 변환하는 과정 |
| 종합점수(Aggregate Score) | 정규화된 기준 값과 가중치를 결합하여 산출한 최종 평가값 |

## 3. 대표적인 MCDA 기법

### 3.1 단순가중합법(Simple Additive Weighting, SAW)

각 기준의 정규화된 값에 가중치를 곱한 뒤 이를 모두 합산하여 종합점수를 구하는 방법이다. GIS 분야에서는 가중선형결합법(Weighted Linear Combination, WLC)이라는 명칭으로도 널리 알려져 있다. 계산 절차가 직관적이고 결과 해석이 쉬워 공공정책 및 입지분석 분야에서 가장 널리 사용되는 방법 중 하나이다.

### 3.2 계층분석법(Analytic Hierarchy Process, AHP)

Thomas Saaty가 제안한 방법으로, 평가 기준들을 계층 구조로 정리한 뒤 기준을 둘씩 짝지어 상대적 중요도를 비교(쌍대비교)하고, 비교 결과를 행렬로 구성하여 수학적으로 가중치를 산출한다. 쌍대비교 과정에서 응답의 논리적 일관성을 확인하는 일관성비율(Consistency Ratio, CR) 지표를 함께 산출하는 것이 특징이다.

### 3.3 TOPSIS

Hwang과 Yoon이 제안한 방법으로, 가상의 "가장 이상적인 대안(Positive Ideal Solution)"과 "가장 열등한 대안(Negative Ideal Solution)"을 설정한 뒤, 각 대안이 이상적인 대안과는 가깝고 열등한 대안과는 먼 정도를 기준으로 순위를 정한다.

### 3.4 그 외 기법

ELECTRE, PROMETHEE 등의 아웃랭킹 방법은 대안들을 둘씩 비교해 우위를 판정하는 방법으로, 특정 기준에서 지나치게 낮은 대안을 다른 기준의 높은 값으로 상쇄하지 않고 배제해야 하는 문제에 주로 활용된다. 계산 절차가 SAW나 TOPSIS보다 복잡하고, 판정 기준을 정하는 데 추가적인 판단이 필요하다는 것이 특징이다.

## 4. 정규화(Normalization) 방법

3절에서 살펴본 기법들을 적용하려면, 그에 앞서 기준값을 동일한 척도로 맞추는 절차가 선행되어야 한다. 평가 기준들은 대체로 서로 다른 단위와 값의 범위를 가지므로(예: 인구밀도는 명/㎡, 거리는 m), 이를 그대로 합산하면 값의 범위가 큰 기준이 결과에 과도한 영향을 미치게 된다. 이를 방지하기 위해 정규화를 통해 모든 기준 값을 동일한 척도(대체로 0~1)로 변환한다.

- **최소-최대 정규화(Min-Max Normalization)**: 각 값에서 최솟값을 뺀 뒤 값의 범위(최댓값-최솟값)로 나누어 0~1 사이의 값으로 변환하는 방법이다. 계산이 단순하나 이상치(outlier)의 영향을 크게 받는다.
- **표준점수(Z-score) 정규화**: 평균과 표준편차를 이용해 값을 변환하는 방법으로, 데이터의 분포 특성을 반영한다.
- **비율 척도(Ratio-based) 정규화**: 각 값을 전체 합 또는 최댓값에 대한 비율로 표현하는 방법이다.

기준의 방향이 "값이 클수록 유리한 기준"인지 "값이 작을수록 유리한 기준"인지에 따라, 정규화 이후 값을 그대로 사용하거나 (1-정규화값)과 같이 반전하여 사용해야 한다.

## 5. 가중치 결정 방법

가중치는 기준 간 상대적 중요도를 나타내며, 결정 방식에 따라 결과가 달라질 수 있다. 대표적인 결정 방법은 다음과 같다.

- **전문가 판단 또는 팀 토론**: 관련 분야 지식을 가진 사람(들)이 경험과 근거에 기반하여 가중치를 직접 정하는 방법이다.
- **쌍대비교(AHP)**: 기준을 둘씩 비교하여 상대적 중요도를 수치화하고, 이를 수학적으로 처리하여 가중치를 산출하는 방법이다.
- **델파이 기법(Delphi Method)**: 다수의 전문가에게 익명으로 의견을 수집하고, 그 결과를 반복적으로 공유·조정하여 합의된 가중치를 산출하는 방법이다.
- **엔트로피법(Entropy Method)**: 데이터 자체의 분산 정도를 기준으로 가중치를 산출하는 방법으로, 주관적 판단을 배제하고 자료의 변별력에 따라 가중치를 정한다.

어떤 방법을 사용하더라도 가중치는 근본적으로 사람의 판단이나 데이터의 특성에 좌우되는 값이므로, 절대적으로 객관적인 가중치는 존재하지 않는다고 보는 것이 일반적이다.

## 6. GIS 기반 입지 적합성 분석(GIS-MCDA)

MCDA에서 각 대안이 지도상의 위치(격자, 행정구역, 지점 등)를 가질 때 이를 공간 다기준분석(Spatial MCDA, GIS-MCDA)이라 한다. GIS-MCDA는 일반적으로 다음과 같은 절차로 수행된다.

1. **문제 정의**: 분석의 목적과 평가 대상 지역을 설정한다.
2. **기준도(Criteria Map) 작성**: 평가에 사용할 각 기준을 공간 데이터(레이어)로 구축한다.
3. **표준화(정규화)**: 각 기준도의 값을 동일한 척도로 변환한다.
4. **가중치 부여**: 기준별 상대적 중요도를 결정한다.
5. **중첩 분석(Overlay Analysis)**: 정규화된 기준도에 가중치를 적용하여 결합하고, 적합도 점수(종합점수)를 산출한다.
6. **결과 검증**: 산출된 결과의 신뢰성을 다양한 방식으로 검토한다.

GIS 환경에서는 대안을 격자(grid) 단위로 정의하는 경우가 많으며, 이 경우 각 기준의 값은 격자별로 산출된 뒤 정규화·가중합 과정을 거쳐 격자 단위의 최종 적합도 점수로 완성된다.

여기까지의 절차는 정도의 차이로 평가되는 기준을 가중합으로 통합하는 과정이었다. 그런데 실제 분석에서는 정도의 문제가 아니라 애초에 후보에서 배제해야 할 지역도 함께 고려해야 하며, 이는 다음 절에서 다룬다.

### 6.1 적합도 기준과 제약조건의 구분

GIS-MCDA에서 사용하는 공간 데이터(레이어)는 성격에 따라 두 가지로 구분된다.

- **적합도 기준(Factor)**: 정도의 차이로 평가되는 연속값 레이어이다. 앞서 배운 정규화·가중치 부여 절차를 거쳐 종합점수에 반영된다.
- **제약조건(Constraint)**: "가능/불가능"과 같이 이진값으로 평가되는 레이어이다. 예를 들어 하천, 법적 규제 구역, 기존 시설 부지 등은 정도의 차이가 아니라 해당 위치를 분석 대상에서 제외할지 여부의 문제이다.

두 레이어를 결합하는 대표적인 연산이 **불리언 중첩(Boolean overlay)**이다. 제약조건 레이어를 0(제외)과 1(포함)로 표현한 뒤, 가중합으로 산출된 적합도 점수에 곱하여 제외 대상 지역의 점수를 0으로 처리하는 방식이 흔히 사용된다. 가중선형결합(WLC)과 불리언 중첩은 GIS 기반 의사결정에서 가장 널리 쓰이는 두 가지 결합 방식으로, 함께 적용되는 경우가 많다. 즉 "어느 지역이 더 적합한가"는 적합도 기준으로, "애초에 후보가 될 수 없는 지역은 어디인가"는 제약조건으로 별도 처리하는 것이 일반적인 절차이다.

## 7. 민감도 분석(Sensitivity Analysis)의 필요성

지금까지 살펴본 정규화 방법, 가중치, 격자 간격 등은 분석자가 직접 설정해야 하는 값이며, 이 값에는 절대적인 정답이 없는 경우가 많다. 따라서 설정값을 변경하였을 때 결과가 얼마나 달라지는지 확인하는 절차가 필요하며, 이를 민감도 분석이라 한다.

민감도 분석을 통해 다음을 확인할 수 있다.

- 특정 설정값의 변화에 결과가 크게 영향을 받는지, 안정적으로 유지되는지 여부
- 여러 시나리오(가중치 조합, 분석 단위 등)에서 공통적으로 우선순위가 높게 나타나는 대안의 존재 여부
- 분석 결과의 신뢰 구간 또는 불확실성의 범위

민감도 분석에서 여러 설정값에 걸쳐 일관되게 상위권으로 나타나는 대안은 상대적으로 신뢰도 높은 결과로 간주할 수 있다.

---

## 8. MCDA 및 GIS-MCDA의 한계

민감도 분석은 결과의 안정성을 확인하는 절차이지만, 그 자체로 방법론의 근본적인 한계까지 해소하지는 못한다. MCDA 기반 입지 적합성 분석은 다음과 같은 근본적인 한계를 갖는다.

- **가중치의 주관성**: 가중치는 결정 방법과 관계없이 결국 사람의 판단(또는 판단이 반영된 데이터)에 의존하므로, 가중치를 정하는 주체가 달라지면 결과도 달라질 수 있다.
- **기준 간 상관관계**: 서로 강한 상관관계를 갖는 기준을 동시에 사용할 경우, 해당 특성이 가중치 이상으로 결과에 중복 반영될 수 있다.
- **정규화 방법에 대한 민감도**: 동일한 데이터라도 정규화 방법에 따라 결과가 달라질 수 있다.
- **공간 단위 설정의 영향(가변 공간 단위 문제, Modifiable Areal Unit Problem, MAUP)**: 동일한 지역이라도 분석에 사용하는 공간 단위(격자 크기, 행정구역 경계 등)를 어떻게 설정하느냐에 따라 통계적 결과가 달라질 수 있다.
- **적합도와 실현 가능성의 구분**: MCDA를 통해 산출된 적합도 점수는 "해당 위치가 목적에 얼마나 부합하는가"를 나타낼 뿐, "해당 위치에 실제로 시설을 건립할 수 있는가"라는 물리적·법적 실현 가능성까지 보장하지는 않는다. 따라서 적합도 분석 결과를 실제 부지 선정에 활용하기 위해서는 별도의 제외 조건(하천, 기존 시설 부지, 급경사지, 법적 규제 등)에 대한 추가 검토가 필요하다.

이러한 한계는 MCDA 방법론 자체의 결함이라기보다, 방법론이 다루는 문제의 성격(다수의 주관적 판단이 개입되는 의사결정)에서 비롯되는 것으로 이해된다. 따라서 분석 결과를 제시할 때에는 산출값 자체뿐 아니라, 어떤 가정과 설정 하에 산출된 값인지도 함께 밝혀야 한다. 그 한계가 무엇인지를 함께 명시하는 것이 일반적인 권장 사항으로 다루어진다.

# 제2부. 실습 절차

제1부에서는 입지 적합성 분석과 MCDA의 기본 개념과 이론을 살펴보았다. 이제부터는 그 이론을 실제 프로젝트에 적용해 본다. 이번 프로젝트는 **서울 노원구를 대상으로 한 재난 대피소 입지 선정**이다. 앞서 배운 GIS-MCDA 절차와 민감도 분석을 실행 순서로 재구성한 표를 아래에 제시하며, 각 단계에서 어떤 근거로 어떤 값을 결정했는지 "결정사항" 칸에 직접 기록해 나간다. 이 프로젝트에서 사용하는 데이터는 다음 3종이다.

1. **인구 데이터**: 행정동 경계 및 인구 통계 (SGIS)
2. **기존 대피시설 데이터**: 전국민방위대피시설표준데이터 (공공데이터포털)
3. **도로망 데이터**: 도로중심선 (국토교통부)

## 1. GIS-MCDA 실행 절차 (제1부 6절 관련)

이 6단계 절차를 실행 단위로 나누면 다음과 같다.

| 순서 | 실행 내용 | 확인·결정할 사항 | 결정사항 (기입) |
|---|---|---|---|
| 1 | 문제 정의 | 분석 목적, 대상 지역, 대안 단위(격자·행정구역 등)와 그 크기 |  |
| 2 | 기준도 작성 | 사용할 기준의 종류와 개수, 각 기준의 데이터 출처 |  |
| 3 | 좌표계 확인 | 모든 레이어의 좌표계 일치 여부, 분석용 투영좌표계 선정 |  |
| 4 | 기준별 점수화 | 각 기준을 대안 단위(격자 등)에 부여하는 방법, 값의 방향(클수록 유리/불리) |  |
| 5 | 정규화(제1부 4절) | 기준별 정규화 방법(최소-최대/표준점수/비율) 선택, 방향 반전 여부 |  |
| 6 | 가중치 부여(제1부 5절) | 가중치 결정 방법(전문가 판단/AHP/델파이/엔트로피법), 기준별 가중치 값 |  |
| 7 | 제약조건 처리(제1부 6.1절) | 적합도 기준과 제약조건의 구분, 제외 대상 레이어의 유무 |  |
| 8 | 중첩 분석 | 결합 방식(가중선형결합/불리언 중첩 등), 사용 도구 |  |
| 9 | 결과 검증 | 결과를 어떤 방식으로 확인할 것인지(육안 검토, 통계적 비교 등) |  |

각 행의 "결정사항" 칸에는 값 자체뿐 아니라 그렇게 판단한 근거도 함께 기록해 두면, 이후 2절(민감도 분석)과 제1부 8절(한계)에서 다루는 검증·한계 서술에 필요한 재료가 된다.

> 노원구 사례로 위 표의 "결정사항" 칸을 채운 예시는 [예시](sub/02-0_입지적합성분석_실행절차_예시_노원구.md) 파일에서 확인할 수 있다.

## 2. 민감도 분석 실행 절차 (제1부 7절 관련)

민감도 분석을 실행 단위로 나누면 다음과 같다.

| 순서 | 실행 내용 | 확인·결정할 사항 | 결정사항 (기입) |
|---|---|---|---|
| 1 | 검토 대상 변수 선정 | 어떤 설정값의 민감도를 확인할 것인지(대안 단위 크기, 가중치, 정규화 방법 등) |  |
| 2 | 대안 시나리오 구성 | 각 변수에 대해 몇 개의 대안 값을 비교할 것인지, 그 값의 범위 |  |
| 3 | 재산출 | 각 시나리오별로 1절의 절차(정규화~중첩 분석)를 다시 수행 |  |
| 4 | 비교 지표 설정 | 시나리오 간 결과를 비교할 기준(예: 상위 순위 목록의 일치 정도, 점수 분포의 변화) |  |
| 5 | 결과 해석 | 어떤 대안이 여러 시나리오에서 공통적으로 안정적인 순위를 보이는지 확인 |  |
| 6 | 기록 | 시나리오 변경에 따른 결과 변화와, 그 과정에서 확인된 한계(제1부 8절 참고) |  |

민감도 분석은 하나의 변수만 변경하는 경우와 여러 변수를 동시에 변경하는 경우로 나눌 수 있다. 전자는 개별 변수가 결과에 미치는 영향을 독립적으로 확인하는 데 유리하고, 후자는 실제 분석에서 발생할 수 있는 복합적인 불확실성을 확인하는 데 유리하다. 어느 방식을 선택할지도 위 표의 1번 항목("검토 대상 변수 선정")에서 함께 결정해 기록한다.
